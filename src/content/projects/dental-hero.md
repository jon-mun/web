### Overview

An educational mobile app designed to teach children dental hygiene through a gamified 30-day brushing challenge. Includes simple AR elements to make the learning experience interactive.

### What I Did

- Implemented mobile functionality using Flutter.
- Integrated Firebase for storage and real-time data.
- Integrated ARCore into Flutter for interactive elements.

### Challenges

- Handling ARCore integration within Flutter’s limitations.
- Designing features that are both educational and engaging for children.
